# Semana 12 - Haskell II: Listas, Tuplas y Recursion

El capstone de esta semana vive en la subcarpeta `estadisticas-hs/`.

## Capstone

[estadisticas-hs/](estadisticas-hs/) - Modulo de estadisticas que calcula
promedio, maximo, orden y aprobados sobre una lista de estudiantes.

## Que se aprendio

En Haskell no hay bucles: se recorre una lista con recursion o con funciones de
orden superior. Las comprensiones de lista filtran y transforman con la misma
notacion que los conjuntos en matematicas. Mantener el modulo de calculo libre
de IO lo vuelve trivial de probar.
