# Semana 06 - Maven y JUnit

El capstone de esta semana es un proyecto Maven completo que vive en la
subcarpeta `sistema-estudiantes/`.

Ahi estan el `pom.xml`, el codigo en `src/main/java`, la suite de tests en
`src/test/java` y el README con el detalle de cada prueba.

## Capstone

[sistema-estudiantes/](sistema-estudiantes/) - Sistema de Estudiantes con
HashMap, TreeSet y 10 tests de JUnit 5.

## Que se aprendio

Maven como gestor de dependencias y ciclo de vida, la estructura estandar de
un proyecto Java, y pruebas automatizadas con JUnit 5.
