# Semana 08 - Vaadin: Grid, Binder y CRUD

El capstone de esta semana vive en la subcarpeta `gestor-tareas/`.

## Capstone

[gestor-tareas/](gestor-tareas/) - Gestor de Tareas con tabla editable,
formulario validado y CRUD completo en memoria.

## Que se aprendio

Grid como tabla de datos, Binder para enlazar un formulario con un objeto y
validar sus campos, y el patron de usar una clase mutable auxiliar cuando el
modelo real es un record inmutable.
