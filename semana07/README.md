# Semana 07 - Vaadin: Fundamentos

El capstone de esta semana es una aplicacion web Vaadin + Spring Boot que vive
en la subcarpeta `gestor-tareas/`.

## Capstone

[gestor-tareas/](gestor-tareas/) - Gestor de Tareas con una vista unica que
permite agregar tareas a una lista en memoria y verlas como texto plano.

## Que se aprendio

Vaadin como framework de UI escrito en Java puro, sin HTML ni JavaScript a mano.
La anotacion @Route publica una vista en una URL, los layouts organizan los
componentes, y las lambdas de los botones se ejecutan en el servidor.
