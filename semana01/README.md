# Semana 01 - Git y entorno

## Que se hizo

Inicialice el repositorio con `git init -b main`, configure la identidad local
con mi cuenta de GitHub, cree el `.gitignore` para Java, Maven y Haskell, arme
la estructura de 16 carpetas de semana y publique todo en GitHub.

## Como se ejecuta

N/A esta semana: el entregable es el repositorio mismo, no un programa.

## Que se aprendio

Git registra la historia y GitHub la publica. Los tres estados de un archivo:
working directory, staging area y repository. El `.gitignore` se crea antes del
primer `git add`, porque despues hay que purgar lo que ya quedo rastreado. Los
mensajes siguen Conventional Commits: `feat:`, `fix:`, `chore:`, `docs:`.
