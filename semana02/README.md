# Semana 02 - Fundamentos de Java

## Capstone: Sistema de Calificaciones

Programa de consola que gestiona las notas de 5 estudiantes con 3 calificaciones
cada uno, calcula estadisticas por estudiante y determina si aprobo.

## Archivos

- `src/Fundamentos.java` - tipos primitivos, operadores, control de flujo, arrays y metodos
- `src/SistemaCalificaciones.java` - el capstone

## Como compilar y ejecutar

    javac -d out src/SistemaCalificaciones.java
    java -cp out SistemaCalificaciones

## Que se aprendio

Tipos primitivos, division entera vs decimal, operadores logicos con cortocircuito,
if/else, switch expression, bucles for/while, arrays 1D y 2D, metodos static con
sobrecarga y entrada validada con Scanner y try-catch.
