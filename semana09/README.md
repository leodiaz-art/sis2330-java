# Semana 09 - Vaadin: Router y Vistas

El capstone de esta semana vive en la subcarpeta `gestor-tareas/`.

## Capstone

[gestor-tareas/](gestor-tareas/) - Gestor de Tareas con tres rutas, menu lateral
compartido y detalle por ID.

## Que se aprendio

El router de Vaadin publica cada vista en una URL y las envuelve en un layout
comun. HasUrlParameter recibe valores desde la propia URL, y RouterLink navega
sin recargar la pagina.
